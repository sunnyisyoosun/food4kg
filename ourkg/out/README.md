# `out/` — 산출물 배치

평평한 폴더에 97 개가 쌓여 **무엇이 정본이고 무엇이 민감도 기록인지 구분이 안
갔다.** 파생물만 하위 폴더로 내렸다 (§54).

| 어디 | 무엇 | 수 |
|---|---|---:|
| `out/` | **정본** — 추천·구축·평가. 코드 167 곳·문서 85 곳이 가리키므로 그대로 둔다 | 56 |
| `out/sweep/` | 쓸기 민감도표 `*_comparison.csv` — 설정을 바꿔 가며 잰 비교표 | 22 |
| `out/complication/` | 합병증 추론 — 소스별 초기하·포개짐·문헌 lift | 10 |
| `out/consensus/` | 부트스트랩 합의 — 설정별 선택도 | 6 |
| `out/metabolome/` | 코호트별 대사체-균 상관 (정본 `compound_microbe_measured.csv` 는 위에 있다) | 2 |
| `out/legacy/` | **생산 코드가 없는 기록.** 지우지 않는 이유는 그 폴더 README 에 있다 | 5 |

## 규칙은 코드에 있다

배치 규칙은 `common.OUT_SUB` 한 자리이고, 쓰는 쪽과 읽는 쪽이 모두
`common.outp(name)` 을 쓴다. `os.path.join(OUT, name)` 으로 되돌리면 파생물이
평평한 자리에 떨어지는데, 그것을 **사람 눈이 아니라 검사가 본다** —
`check.py outputs` 의 `파생물 폴더 배치`.

**파일명은 ASCII 만 쓴다.** `consensus_<설정>.csv` 의 설정 키가 `현행` 이라
`consensus_현행.csv` 가 생겼다(키가 그대로 파일명이 되는 구조라 파일만 고치면
다시 생긴다). 키를 `current` 로 바꾸고 `산출물 이름 ASCII` 검사를 붙였다.

## 정본이 기본값으로 만들어졌는지

`out/provenance.json` 이 산출물마다 **어느 스크립트가 · 언제 · 어떤 비기본값
환경변수로** 만들었는지 기록한다. `check.py provenance` 가 정본 중 비기본값으로
만들어진 것이 있으면 FAIL 한다.
